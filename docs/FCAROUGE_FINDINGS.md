# Findings for the FrancoisCarouge projects

Shortcomings, frictions and improvement opportunities in
[FrancoisCarouge/Kalman](https://github.com/FrancoisCarouge/Kalman) and
[FrancoisCarouge/TypedLinearAlgebra](https://github.com/FrancoisCarouge/TypedLinearAlgebra), found while
integrating them into ArduPilot. See [FCAROUGE_KALMAN_PLAN.md](FCAROUGE_KALMAN_PLAN.md) for the
integration plan.

Status: open (not reported upstream yet), reported. Resolved and withdrawn findings are removed; numbers are not reused.

Rechecked on 2026-10-15 against Kalman 59c6e0d19, TypedLinearAlgebra db34d69db and mp-units ef8653eab. Removed: F1, F3, F30, F32 (fixed upstream), F19 (withdrawn).

| F2 | Kalman | Embedded, build | `kalman.hpp` always includes `<print>` and `<format>` through `print.hpp` and `format.hpp`, even when no formatting is used, and declares `inline constexpr printer print` so the headers cannot be skipped. Blocker for ArduPilot firmware: ArduPilot's ChibiOS build replaces `stdio.h` with a minimal header without `FILE` or `fwrite`, so `<print>` fails (`'fwrite' is not a member of 'std'`) and no Kalman filter can build for a flight controller. | F18 | Both | Usability | The backend contract includes divisions that only form types: Kalman takes `state / state` (transition matrix type) and `scalar / state` (output model type for a scalar output). | F20 | TLA | Usability | A 1xN or Nx1 typed matrix is rank 1 and rejects two-index access (`element<0, j>`, `at<0, j>`) through a sentinel type with deleted special members; the error is "use of deleted function ~type()". Generic filter code (an output model is z x n) breaks when the output count is 1. Likewise a 1x1 typed vector is rank 0 and rejects `at<0>()`, requiring `at()`. | Thermal EKF output model, 1x4; again generic element type traits in `AP_LinearAlgebra` (`ElementType`), which must dispatch on the shape because `element<i, j>` is unusable on vectors.; also the cause of the thermal EKF's named element variables first attributed to F19; 2026-10-11: a quadratic form `transposed(y) / S * y` is a 1x1 typed matrix, not its element, read with `at()` | Allow full-rank indexing on vectors (index 0 on the unit dimension), or a readable `static_assert`. | open |
| F21 | Kalman | Embedded, correctness | `one<>` and `zero<>` are non-`constexpr` `inline` variable templates: each instantiation is a global object with dynamic initialization. The 4-state thermal EKF uses 360 B of RAM (data + bss) for them on Cortex-M4, and 4072 B of code versus 1040 B for the hand-written filter it replaces. Correctness: their dynamic initialization is unordered across translation units, so a filter constructed during static initialization (a member of a global object, as ArduPilot vehicles hold their libraries) can copy them before they are set. The precision landing filter, a member of the global `AC_PrecLand`, got a zero output model: gain zero, the estimate never corrected, landings 2.9 m and 52 m off target in SITL. Unit tests with local filters pass. | `arm-none-eabi-size` of the probe and of `AP_Soaring/ExtendedKalmanFilter` + `matrixN`.; `AC_PrecLand/PosVelEKF` in `Copter.PrecisionLanding`, reproduced by `test_posvelekf` `StaticStorage` (a global filter); ArduPilot constructs the filter on its first `init()` instead. 2026-10-11: the filters' identity `i` of the Joseph update is a `static inline const` member copied from `one<>`, another unordered dynamic initialization, between two templated variables of the same translation unit; the EKFGSF filters are built when the estimator is, and built again on each reset, at run time; 2026-10-15: reproduced on Kalman 59c6e0d19 with three translation units and a type whose `identity()` returns a value (g++ 14, clang 21: the global copy is zero when its unit is initialized first); the Eigen backend hides it, its `Identity()` is an empty expression object that evaluates to the identity even uninitialized, so the library's own tests cannot show it. Recorded as defect 10 of Kalman's `todo` branch `BUG.md` | Make them `constexpr` (or functions returning the value) so no filter can observe them uninitialized; until then, document that a filter must not be constructed during static initialization. | open |
